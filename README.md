# Into the Deep v2

A GitHub Pages-ready interactive deep-sea descent.

## Features
- Continuous 0–10,924 m depth readout driven by page scrolling
- Sunlight, Twilight, Midnight, Abyssal and Hadal zone markers
- Organism encounters throughout the descent
- Click/tap any organism to open its profile
- Source-provided organism imagery and source-provided facts where available
- Responsive mobile layout
- No build step, framework, or backend required

## GitHub Pages
Upload `index.html` to a repository, then enable:
**Settings → Pages → Deploy from a branch → main → / (root)**.
